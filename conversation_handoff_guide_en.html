Move Your Conversation.
Pick Up Right Where You Left Off.

A practical guide to using the Conversation Handoff skill to create, update, and finalize a handoff file—then continue your work in a new chat without starting over.

The core idea: A handoff file carries your working context, decisions, and current progress into a new conversation. Create it before the chat becomes too long or difficult to manage.

01 — In the Original Conversation

Choose the situation that matches your needs, then use the suggested prompt.

When moving a conversation for the first time

Use this mode to create an initial handoff file summarizing the current context and progress.

Create a handoff summary

When the conversation is getting long—or you need a final handoff

Ask the assistant to prepare the conversation for transfer and review the file for completeness and quality.

Prepare this conversation for handoff

When you already have a previous handoff file

Attach the previous file or paste its contents, then ask the assistant to merge the latest developments into it rather than creating a separate summary.

Update the handoff summary
Default behavior: If you do not specify a mode, the skill uses Create—or Update if a previous handoff file is available.

Natural-language requests with the same meaning work too—for example: “This conversation is getting too long. Summarize it so I can continue in a new chat.”

You can add a specific instruction after the trigger phrase, such as: “Create a handoff summary and focus on the final approved code.”

02 — In the New Conversation

Attach the handoff file, then choose how you want to resume.

  1. 1

    Attach the file
    Attach CONVERSATION_HANDOFF.md or paste its full contents into the new conversation.

  2. 2

    Send the appropriate continuation prompt
    Choose one of the following depending on how you want the assistant to proceed.

Normal continuation — Continue from the handoff file.
Start the next task — Start with NEXT ACTION and execute the next task.
Verify understanding — Read the file, summarize where we left off in two lines, then begin.
Why is a short prompt enough? The handoff file itself contains a standing instruction for the new assistant: read the full context, do not start from scratch, do not reopen approved decisions, and begin with NEXT ACTION.

03 — Review the File After It Is Created

If you spot missing information or an incorrect detail, request a precise correction.

04 — Complete Workflow Example

A simple sequence from creating the file to updating it after another work session.

Example scenario
[Original conversation]
You:       Create a handoff summary
Assistant: Creates CONVERSATION_HANDOFF.md

[New conversation]
You:       Attach the file, then type: Continue from the handoff file.
Assistant: Resumes directly from NEXT ACTION.

[After another work session]
You:       Attach the previous file, then type: Update the handoff summary
Assistant: Merges the latest progress into the handoff file.

One final recommendation

Do not wait until the conversation becomes unusable or important context is lost. Run the skill as soon as the conversation starts feeling long or difficult to manage, and keep the handoff file somewhere easy to access.

Use the Copy buttons to transfer any prompt directly into your conversation.
